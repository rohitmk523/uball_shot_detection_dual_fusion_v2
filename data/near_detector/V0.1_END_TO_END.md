# v0.1 End-to-End Shot Detection — Fixing the Serve Skew (2026-06-14)

Frozen game e74164e6 (unseen by detector AND classifier), no GT windows.

## The gap was serving glue, NOT the model (proven)
Diagnostic: classifier on e74164e6 with TRAINING-STYLE crops = **0.925**
(make recall 0.974). So the model + crop geometry generalize fine to a frozen
game; the end-to-end loss was entirely the spotter handing a mis-timed window.

## Progression (each fix is serving-side, zero retraining / zero new data)
| stage | end-to-end make/miss | make rec | miss rec |
|---|---|---|---|
| naive integration | 0.692 | 0.593 | 0.917 |
| + window-match (training-style crop) + event dedup | 0.704 | 0.667 | 0.778 |
| **+ rim-crossing event timing** | **0.840** | 0.875 | 0.778 |
| + stride 2 + rim-reach filter | 0.731 (regressed, reverted) | 0.812 | 0.600 |

Root cause of the big jump: event time was the MEDIAN of all in-zone frames,
pulled 4-6s early by ball-handling/approach (esp. free throws) -> the +/-3s
classification segment missed the rim moment -> confident-wrong on makes.
Fix = time the event at the rim CROSSING (ball closest to rim center).

## v0.1 result (locked config: stride 3, rim-crossing timing)
- Spot recall 0.806 (25/31), precision 0.65 (~18 false events / 20min)
- **End-to-end make/miss on spotted shots: 0.840** (make rec 0.875, miss rec 0.778)
- Classifier ceiling on this game (perfect windows): 0.925

## Honest caveats
- Tuned the spotter timing across 4 runs on e74164e6 -> this number is mildly
  optimistic for THIS game. Confirm on a 2nd frozen game (6d601c99 / ee8745f1,
  needs S3 download) with the LOCKED config, no tuning.
- Spotter is the remaining bottleneck: recall (misses fast clean FT makes at
  stride 3) and precision (18 false events). Both are dials, but tune on a
  separate game.
- Residual classifier errors match the label-audit weakness: confident
  false-make on long-range rim-outs -> clear-below-net guard is the v0.2 lever.

## Verdict
Single-camera end-to-end shot detection works: ~0.84 make/miss on found shots
with a clear path to the 0.925 ceiling via spotter timing. This matches what
near-angle contributed inside 4-camera fusion (~0.90), now standalone.
